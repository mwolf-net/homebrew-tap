# mwolf-net Homebrew tap

Homebrew casks for apps by [mwolf-net](https://github.com/mwolf-net).

## MouseLock

[MouseLock](https://github.com/mwolf-net/mouselock) is a macOS menu bar app
that locks the mouse pointer to one display.

    brew install --cask mwolf-net/tap/mouselock

Upgrade with `brew upgrade --cask mouselock`. The cask is updated
automatically when a new MouseLock release is published.
