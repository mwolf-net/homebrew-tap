# mwolf-net Homebrew tap

Homebrew casks for apps by [mwolf-net](https://github.com/mwolf-net).

## Martin's Display Helpers

[Martin's Display Helpers](https://github.com/mwolf-net/MartinsDisplayHelpers)
(formerly MouseLock) is a macOS menu bar app for working with more than one
screen.

    brew install --cask mwolf-net/tap/martins-display-helpers

Upgrade with `brew upgrade --cask martins-display-helpers`. The cask is updated
automatically when a new release is published. The old `mouselock` cask name
points to it.
